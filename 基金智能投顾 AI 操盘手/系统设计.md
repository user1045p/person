# 轻量级高频爬虫 + 实时监控平台 技术文档

## 1. 项目概述

本项目旨在搭建一个 **极致轻量、零外部依赖** 的高频爬虫与实时数据监控系统。  
适用于每秒 3~5 次高频请求、实时数据清洗、WebSocket/SSE 推送及前端高频渲染的场景。

### 核心原则
- 仅使用 **Node.js + npm 包**，不依赖任何外部软件（无 Redis、无外部数据库）。
- 前端极简，无需构建步骤，原生 HTML/JS 即可运行。
- 所有组件运行在单进程中，部署方便。

---

## 2. 技术选型

| 层级     | 技术                      | 说明                                                         |
| -------- | ------------------------- | ------------------------------------------------------------ |
| 后端框架 | Fastify                   | 高性能、插件化，集成 WebSocket 和静态服务                    |
| 爬虫引擎 | Crawlee (CheerioCrawler)  | 内置内存/文件队列，自动控制并发与反封禁                      |
| 数据库   | better-sqlite3            | 纯 npm 包，零配置，单文件数据库，性能极高                    |
| 实时推送 | 原生 WebSocket (ws) + SSE | 通过 `@fastify/websocket` 和 `@fastify/sse` 插件提供双向/单向推送 |
| 数据校验 | Valibot (可选)            | 超轻量 schema 校验，保障清洗后数据结构                       |
| 前端     | 原生 HTML/CSS/JS          | 无框架依赖，通过限制列表长度或轻量虚拟滚动保证高频渲染性能   |
| 包管理   | npm/pnpm                  | 任选，无额外依赖                                             |

```text
┌──────────────────────┐
│ 浏览器 (HTML/JS)      │
│  WebSocket 或 SSE 连接 │
└─────────┬────────────┘
          │
┌─────────▼────────────┐
│  Fastify 服务         │
│  - 静态文件托管       │
│  - WebSocket / SSE    │
│  - API 路由（可选）   │
└─────────┬────────────┘
          │
          │ 内存中直接调用
          ▼
┌────────────────────────────┐
│  Crawlee 爬虫逻辑          │
│  - CheerioCrawler          │
│  - 内存/文件 RequestQueue   │
│  - 每请求 → 清洗 → 存储/推送│
└─────────┬──────────────────┘
          │
          ▼
┌────────────────────────────┐
│  SQLite 数据库             │
│  (better-sqlite3)          │
│  单文件存储清洗后数据       │
└────────────────────────────┘
```

所有模块在 **同一个 Node 进程** 中运行，无网络中间件，延迟极低。

## 6. 核心模块实现

### 6.1 后端服务 (server.js)

javascript

```
import Fastify from 'fastify';
import fastifyWebsocket from '@fastify/websocket';
import fastifyStatic from '@fastify/static';
import fastifyCors from '@fastify/cors';
import path from 'path';
import { fileURLToPath } from 'url';
import { startCrawl, stopCrawl, onCrawlData } from './crawler.js';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const fastify = Fastify({ logger: true });

// 注册插件
await fastify.register(fastifyCors);
await fastify.register(fastifyStatic, {
  root: path.join(__dirname, '../public'),
});

// WebSocket 端点
await fastify.register(async (fastify) => {
  fastify.get('/ws', { websocket: true }, (socket, req) => {
    // 注册数据推送回调
    const sendData = (data) => {
      if (socket.readyState === 1) {
        socket.send(JSON.stringify(data));
      }
    };
    onCrawlData(sendData);

    socket.on('message', (rawMsg) => {
      try {
        const { action, payload } = JSON.parse(rawMsg);
        if (action === 'start') startCrawl(payload);
        else if (action === 'stop') stopCrawl();
      } catch (e) {
        console.error('Invalid message:', e);
      }
    });

    socket.on('close', () => {
      // 移除回调（简单起见，可通过 Map 管理）
    });
  });
});

// 可选的 HTTP API（方便调试）
fastify.post('/api/start', async (req) => {
  await startCrawl(req.body);
  return { status: 'started' };
});

fastify.post('/api/stop', async (req) => {
  await stopCrawl();
  return { status: 'stopped' };
});

// 启动服务
const start = async () => {
  try {
    await fastify.listen({ port: 3000, host: '0.0.0.0' });
    console.log(`Server running at http://localhost:3000`);
  } catch (err) {
    fastify.log.error(err);
    process.exit(1);
  }
};
start();
```



### 6.2 爬虫引擎 (crawler.js)

javascript

```
import { CheerioCrawler, RequestQueue } from 'crawlee';
import { insertData } from './db.js';
import { cleanData } from './cleaner.js';

let crawler = null;
const dataCallbacks = new Set();

// 注册监听器，供 WebSocket 使用
export function onCrawlData(cb) {
  dataCallbacks.add(cb);
  return () => dataCallbacks.delete(cb);
}

function pushToClients(item) {
  for (const cb of dataCallbacks) {
    cb(item);
  }
}

export async function startCrawl({ urls, maxConcurrency = 10 }) {
  if (crawler) {
    console.log('Crawler is already running');
    return;
  }

  // 使用内存队列，也可配置为本地文件持久化
  const requestQueue = await RequestQueue.open();

  crawler = new CheerioCrawler({
    requestQueue,
    maxConcurrency,               // 控制并发，默认 10，可满足每秒 3-5 次请求
    requestHandler: async ({ request, $ }) => {
      // 实际抽取逻辑按需修改
      const rawItem = {
        url: request.url,
        title: $('title').text().trim(),
        // 可根据需要提取更多字段
      };

      // 数据清洗
      const cleaned = cleanData(rawItem);

      // 存入数据库
      insertData(cleaned);

      // 实时推送到前端
      pushToClients(cleaned);
    },
    // 可选：自动代理、限制请求速率等
    // maxRequestsPerMinute: 300,
  });

  // 添加初始 URL
  await requestQueue.addRequests(urls.map(u => ({ url: u })));

  // 非阻塞执行（将抓取置于后台）
  crawler.run().then(() => {
    console.log('Crawler finished');
    crawler = null;
  }).catch((err) => {
    console.error('Crawler error:', err);
    crawler = null;
  });
}

export async function stopCrawl() {
  if (crawler) {
    await crawler.teardown();
    crawler = null;
    console.log('Crawler stopped');
  }
}
```



### 6.3 数据库模块 (db.js)

javascript

```
import Database from 'better-sqlite3';
import path from 'path';
import { fileURLToPath } from 'url';
import fs from 'fs';

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const dataDir = path.join(__dirname, '../data');

// 确保 data 目录存在
if (!fs.existsSync(dataDir)) {
  fs.mkdirSync(dataDir, { recursive: true });
}

const db = new Database(path.join(dataDir, 'crawl.db'));

// 启用 WAL 模式提升写入性能
db.pragma('journal_mode = WAL');

// 初始化表结构
db.exec(`
  CREATE TABLE IF NOT EXISTS items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    url TEXT NOT NULL,
    title TEXT,
    raw_json TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  )
`);

// 插入数据
const insertStmt = db.prepare(
  'INSERT INTO items (url, title, raw_json) VALUES (@url, @title, @raw_json)'
);

export function insertData(item) {
  insertStmt.run({
    url: item.url,
    title: item.title,
    raw_json: JSON.stringify(item),
  });
}

// 查询最近的数据（供前端初始化或回看）
export function getRecentData(limit = 100) {
  return db.prepare('SELECT * FROM items ORDER BY created_at DESC LIMIT ?').all(limit);
}
```



### 6.4 数据清洗 (cleaner.js)

javascript

```
import { object, string, safeParse } from 'valibot';

// 定义清洗后的数据结构
const CleanedItemSchema = object({
  url: string(),
  title: string(),
});

export function cleanData(raw) {
  // 自定义清洗逻辑：去除空白、截断过长标题等
  const cleaned = {
    url: raw.url?.trim(),
    title: raw.title?.slice(0, 200) || 'No Title',
  };

  // 使用 valibot 校验（如不合法可记录日志并丢弃或补全）
  const result = safeParse(CleanedItemSchema, cleaned);
  if (!result.success) {
    console.warn('Data validation failed:', result.issues);
    // 仍可返回清洗后的数据，但可能缺少某些字段
  }

  return cleaned;
}
```

### 7.2 app.js

javascript

```
const logContainer = document.getElementById('log');
const statusDiv = document.getElementById('status');
const urlInput = document.getElementById('url-input');
const startBtn = document.getElementById('start-btn');
const stopBtn = document.getElementById('stop-btn');

const MAX_LOG_ITEMS = 300; // 最多保留条目，保证 DOM 轻量

// 创建 WebSocket 连接
const socket = new WebSocket(`ws://${location.host}/ws`);

socket.onopen = () => {
  statusDiv.textContent = '已连接 WebSocket';
};

socket.onmessage = (event) => {
  const item = JSON.parse(event.data);
  addLogEntry(item);
};

socket.onclose = () => {
  statusDiv.textContent = '连接已断开';
};

socket.onerror = (err) => {
  console.error('WebSocket error:', err);
  statusDiv.textContent = '连接错误';
};

// 添加日志条目
function addLogEntry(item) {
  const entry = document.createElement('div');
  entry.className = 'log-entry';
  const time = new Date().toLocaleTimeString();
  entry.innerHTML = `<span class="time">${time}</span>
                     <span class="url">${escapeHtml(item.url)}</span>
                     <span>${escapeHtml(item.title)}</span>`;
  logContainer.prepend(entry);

  // 限制 DOM 节点数量
  while (logContainer.children.length > MAX_LOG_ITEMS) {
    logContainer.lastChild.remove();
  }
}

// 简单防 XSS
function escapeHtml(text) {
  return String(text)
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;');
}

// 发送控制指令
startBtn.onclick = () => {
  const urls = urlInput.value.split('\n').map(s => s.trim()).filter(Boolean);
  if (urls.length === 0) {
    alert('请输入至少一个网址');
    return;
  }
  socket.send(JSON.stringify({
    action: 'start',
    payload: { urls, maxConcurrency: 10 }
  }));
  statusDiv.textContent = '爬虫运行中...';
};

stopBtn.onclick = () => {
  socket.send(JSON.stringify({ action: 'stop' }));
  statusDiv.textContent = '已发出停止指令';
};
```



> **高频渲染优化**：通过限制 `MAX_LOG_ITEMS` 为 300，确保即使每秒推送 5 条数据，DOM 也不会无限增长，浏览器重绘压力极小。
> 如需展示海量数据，可引入轻量虚拟滚动库（如 `hyperlist`），但在本场景中 300 条足以满足实时监控需求。

## 9. 扩展与优化

### 9.1 支持 SSE 推送

如需单向推送（无需前端下发指令），可在 Fastify 中注册 `@fastify/sse` 插件：

bash

```
npm install @fastify/sse
```



javascript

```
fastify.get('/sse', async (req, reply) => {
  reply.raw.writeHead(200, {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
    'Connection': 'keep-alive',
  });
  const send = (data) => {
    reply.raw.write(`data: ${JSON.stringify(data)}\n\n`);
  };
  const unsubscribe = onCrawlData(send);
  req.raw.on('close', unsubscribe);
});
```



前端可使用 `EventSource` 连接。

### 9.2 爬虫反封禁策略

在 `crawler.js` 中配置 Crawlee 的选项：

javascript

```
new CheerioCrawler({
  // 限制整体请求速率
  maxRequestsPerMinute: 300,
  // 自动重试
  requestHandler: ...,
  failedRequestHandler: async ({ request }) => {
    console.log(`Request ${request.url} failed`);
  },
  // 自定义请求头
  preNavigationHooks: [async ({ request }) => {
    request.headers = { 'User-Agent': 'Mozilla/5.0 ...' };
  }],
});
```



### 9.3 数据持久化与队列恢复

将 Crawlee 的存储目录配置为本地文件夹：

javascript

```
import { Configuration } from 'crawlee';
Configuration.getGlobalConfig().set('storageClientOptions', {
  localDataDirectory: './crawlee_storage',
});
```



这样重启服务后，未完成的请求会从本地文件恢复。

## 10. 总结

该方案仅需 **Node.js 和 npm**，无任何外部服务依赖，实现了：

- 高频爬取（每秒 3-5 次）且可控并发
- 实时数据清洗与校验
- 通过 WebSocket 毫秒级推送至前端
- 前端极简，支持高频数据渲染，零构建步骤
- 数据持久化至单文件 SQLite，方便备份

**适用场景**：小型到中型爬虫监控项目、内部工具、原型验证。
若未来需扩展为分布式，可将队列和数据库替换为 Redis 和 PostgreSQL，架构调整成本低。
